# NPC 自主行动与信息边界（0.2）

[返回首页](<../README.md>) · [剧本格式](<adventure-format.md>) · [开发与恢复](<development-and-recovery.md>)

## 不是只有台词权

框架在真实玩家输入后、战斗/检定前、进入新场景时，自动询问每位在场且能行动的角色；不需要 DM 先点名或调用 `tavern_speak`。沉默也可以保护你、拒绝合作、暗中干扰或离队。

```text
真实输入/点选 → cultivation 评价亲历行为、保留记忆和信念
→ NPC 按性格、底线、共同经历独立决定
→ runtime 校验证据、目标、场合和能力 → 原子提交规则后果
→ DM 只呈现已发生的公开事实，不批准/取消 NPC 的选择
```

- 好感不是服从按钮；低好感也不等于坏人。角色可以因为职责帮助不喜欢的人，也可以爱护你但拒绝某个要求。没有“好感低于 X 自动背叛”“说够 N 次就翻脸”的阈值。
- `read/shift/next` 是角色私有解读、态度变化与下一步倾向，不原样返回公开工具或交给 DM。关系判断跨场景保留，但不把旧话题当成当前必须继续的对话。
- 未被点名者也会感知玩家行为，不是只有说话者才积累关系。近期亲历世界/NPC 事件是 cultivation 评价上下文，不把整段聊天灌成“已知事实”。
- 行动证据只能引用角色实际感知的事件 ID，不能读取队友秘密、密谋或离队后未亲历的聊天。

这些是运行时的调度与数据约束；NPC 的具体判断、表达自然度与长期性格一致性依赖生成模型，不是规则能保证的人类级自主性。

## 已接入的行动与真实代价

| 行动 | 当前简化规则 |
|---|---|
| 观察/等待 | 不强制行动、不强制全员发言 |
| 协助 | 本次玩家攻击或剧本检定 +2 |
| 使绊子 | 本次玩家攻击或剧本检定 −2；可以公开，也可以暗中发生 |
| 掩护 | 替玩家挡至多 2 点实际伤害，自己留下伤势 |
| 冒险救援 | 挡至多 4 点实际伤害；实际挡伤后掷 d20，1–5 重伤，否则受伤 |
| 保护队友 | 若该队友正在替玩家挡伤，分担其实际伤势代价；不无限连锁转移、不凭空制造 NPC 伤害 |
| 拒绝/翻脸 | 公开拒绝或划清边界，不额外提供协助；不会自动变成离队 |
| 自主离队 | 直接改变本局队伍状态；DM 和玩家不能要求“先批准才准走” |

同次交锋合计修正限制为 ±4，挡伤合计至多 4；自然 1/20 规则不变。敌人没命中或已被击败，不会为制造戏剧让救援者凭空受伤。行动数值来自规则，不接受模型随意填写伤害、装备变化或必胜结果。

暗中干扰的行动者、理由和证据只存在本局私有记录，工具、DM 提示词、队伍面板和队友感知中均不自动披露。玩家可能只看到攻击/检定结果改变，不会自动知道是谁；NPC 后续可以自行公开翻脸或承认。当前不是完整隐匿/侦查系统，也没有任意盗窃、暗杀、装备破坏能力。

队伍面板显示公开自主行动和实际伤势，不显示密谋。安全休整让重伤降为受伤、受伤恢复；不跨空治疗离队者，不清除旧怨或强行加好感。

## 离队与归队

`tavern_leave` 只能请求角色自行决定，不能由 DM 强行赶走；`tavern_return` 是可被拒绝的归队邀请。归队保留伤势和关系，不强制原谅。`tavern_offscreen` 私下结算离队经历，玩家和 DM 不自动获知。

失踪/被俘者不能通过归队工具瞬移回来。完整寻找与营救机制尚未接入，不能把这个 Demo 当成完整独立冒险模拟器。

## 对话、点选与连续性

没有“两位队友后报错”的硬上限；仍按先后接话，不默认全员轮流回答同一个问题。同一次真实输入、同场景、同角色的重复调用幂等。宿主自动把 `ask_user_question` 的实际点选/自定义回答记录成新行动，不依赖 DM 传 `newBeat`；旧参数只为兼容保留，不能用于伪造新输入。

“我认/你说得对”不是禁语，只应在角色真正认可某个具体点时自然使用，而非每轮礼貌开场。眼前有敌人时优先处理当前危险；旧怨可以影响是否/如何出手，但不必停下来重讲第一幕。这些叙事目标仍需真实模型验收。

## 独立 agent 与私有状态

NPC 使用独立 `spawn`、`delivery:caller`，没有完整主会话历史；创建时工具被限制为仅结构化报告，完成后释放 activation。

对白报告只向主会话返回公开台词和动作意向；`read/shift/next`、队友评价 `ally*`、自主决策理由与证据留在本局私有状态，不交给 DM。NPC 不能访问其他人的秘密。感知历史按事件发生时的场景与 audience 过滤，跨场景长回合旁白不倒灌给后来者。

每次新输入可能增加在场角色评价与决策调用，战斗/检定前也会独立判断，比只生成台词更耗时、更耗模型用量。子 agent 超时按未行动降级，不虚构后果。任意 NPC 调用或写盘失败不提交半个角色状态；生成失败可以短暂未回应，关系评价失败不伪造好感变化。
