# dsh-tavern

**在 DSH 里开一场文字冒险，让队友拥有自己的判断。**

一个剧本、一位 DM、你和三名独立 NPC：用自然语言探索地下城、做出选择，让关系、记忆与规则后果留在同一份存档里。

[快速开始](#快速开始) · [示例剧本](<demo/README.md>) · [剧本格式](<docs/adventure-format.md>) · [NPC 自主性](<docs/npc-autonomy.md>) · [开发与恢复](<docs/development-and-recovery.md>)

## 有什么不同

- **主会话是 DM，队友是独立 agent。** 布兰（战士）、莱拉（游侠）、伊琳（牧师）各自通过 `spawn` 思考，不是 DM 一人代写三种口吻；玩家是第四名队员。
- **有记忆，也有边界。** NPC 根据性格、底线和亲历事件判断，可以协助、掩护、拒绝、干扰或离队。好感不是服从按钮，DM 不审批角色的自主选择。
- **叙事交给模型，后果交给规则。** 检定、伤害、行动证据、能力边界和状态提交由运行时校验，模型不能任意填写伤害、装备变化或必胜结果。
- **每一局独立。** 剧本版本与开局快照固定；本局关系、记忆和知情范围不写入日常角色库。存档可在新会话明确接管后继续。
- **剧本是数据，不是插件代码。** 可导入声明式 ZIP 剧本；不执行包内脚本、安装钩子或自定义宿主工具。

> **当前版本：0.2.0，短篇 Demo。** 内置「灰石矿洞」，不是完整 D&D 5e，也不是完整的独立世界模拟器。需要 Node.js 22+、DSH Web、可用的默认模型和 `spawn` 子 agent 服务；宿主适配以 DSH 0.2.1-rc.2 的公开接口为基准。

## 快速开始

### 1. 安装到 DSH

使用 DSH 原生插件命令安装 npm 包，而不是只在任意目录运行 `npm install`：

```sh
npx @deepseek-ai/dsh plugin --profile web add --workspace-root dsh-tavern-adventure
```

GitHub 项目名为 **dsh-tavern**，npm 包名为 **`dsh-tavern-adventure`**。如果曾装过旧名 `dsh-tavern` 的本地 bundle，升级前先备份并停用旧 bundle，勿同时加载两份；[迁移说明](<docs/development-and-recovery.md#审核归档后再发布>)。

`web` 是目标 profile；如果你的原 DSH 使用其他 profile，请替换成实际名称。安装后，**重启原来启动 DSH 的那个进程，再刷新原 DSH Web 地址**。无需另起 Vite 或替代 Web 服务器；安装依赖不会让正在运行的进程自动获得新插件。

### 2. 开始第一局

1. 新建一个**尚未发过消息的空白会话**，点击输入框旁的「地城冒险」。
2. 选择已自动导入的「灰石矿洞」，再选择「新建冒险」。
3. 确认后主会话加载剧本 DM 并介绍开场。你可以直接输入行动；遇到明确分支，DM 也可以通过宿主 `ask_user_question` 提供可点选项。
4. 与三名队友交谈，探索矿洞；从会话标题旁的游戏入口查看生命、场景、回合和暂停状态。

续玩时，在**另一个空白新会话**选择同一剧本与已有存档，明确确认接管。一个存档同时只能由一个会话推进；接管后旧会话只读。旧会话仍在处理回合时会拒绝接管，请等它结束或先在 DSH 取消当前回合。

普通旧会话不能中途转成游戏；游戏会话不能切回通用助手，也不能换绑其他存档。暂停、结束都不解除游戏模式：规则解释和剧情回顾可在局内进行，无关现实任务请另开普通会话。

### 角色能力来自 cultivation

`dsh-cultivation` 提供独立角色的关系、记忆和行为评价能力，也能**脱离 tavern 单独使用**。tavern 自动安装所需依赖（最低 0.4.1，当前声明范围为 `^0.4.1`），不要求先手动安装它。

npm 依赖存在不代表 DSH 自动启用插件，因此 [装载配置](<cordis.patch.yml>) 还提供 cultivation 兜底启动项；同一标准装载组已配置 cultivation 时让位，避免重复启动。复杂嵌套组或表达式禁用行不在首期自动去重保证范围内。如果已有旧版，须让 DSH 实际解析到兼容的 0.4.1+ 服务；接口过旧时会明确报错，不会伪装可用或迁移日常角色。详细验证见[开发文档](<docs/development-and-recovery.md>)。

## 这一版能玩到哪里

「灰石矿洞」从矿口营地出发，经回声岔道选择绕行或战斗，最终抵达晨光出口。可以调查、交谈、检定、撤退休整，再回来面对保留剩余生命的敌人。完成后可回顾，但不能继续改动已结束的游戏。见[示例剧本指南](<demo/README.md>)。

规则使用 d20 + 剧本固定修正，自然 1 失败、自然 20 成功，战斗暴击为双倍固定伤害。每次真实玩家行动只结算一次攻击/反击或移动；DM 不连续代打、连跳场景，真实点选回答会开启新行动。

暂不支持多人联机、常驻 NPC、完整职业/法术/先攻、可视化剧本编辑器、地图生成、任意脚本扩展或不同剧本版本旧局的自动迁移。失踪/被俘后的完整寻找营救机制、任意盗窃/暗杀/装备破坏、完整隐匿侦查系统也尚未接入。

## 数据、隐私与模型用量

- **存档在 DSH 主机磁盘，不在浏览器缓存。** 默认目录为 `$DSH_HOME/tavern`，未设置时为 `~/.dsh/tavern`；远程部署意味着保存在服务器。没有云端存档同步。
- **本地存储不等于离线推理。** 使用在线模型时，DM/NPC 生成所需上下文仍会发送给你配置的模型服务，请勿输入不希望发送的信息。
- **独立 NPC 会增加延迟与费用。** 每次新输入可能触发在场角色的评价和自主决策，战斗/检定前也会判断；实际费用取决于模型供应商。超时按未行动降级，不虚构后果。
- **秘密隔离是运行时数据边界，不是模型表现承诺。** NPC 只获取自己感知的事件，私有解读与暗中行动不会自动交给 DM 或其他队友；沉浸感、判断质量与叙事稳定性仍取决于模型。

备份、损坏报错、锁恢复与单写规则见[数据与恢复](<docs/development-and-recovery.md#本地数据与恢复>)。
