# 灰石矿洞 · 短篇示例

[返回首页](<../README.md>) · [剧本格式与安全限制](<../docs/adventure-format.md>) · [数据恢复](<../docs/development-and-recovery.md#本地数据与恢复>)

玩家「旅人」与战士布兰、游侠莱拉、牧师伊琳组成四人小队。主线从矿口营地出发，经回声岔道选择封印大厅或旧风道，抵达晨光出口。

## 可以尝试

- 先与三名队友交谈、核对名册。营地名册检定提供调查线索；NPC 各有价值观和私人知情范围，不只是职业标签。
- 岔道循风检定成功可绕开战斗救人；失败仍可走大厅路线，不会卡死。
- 大厅有简单 d20 遭遇。可以撤退、回营地休息再来，守卫剩余 HP 不重置。每次真实玩家输入只结算一次攻击/反击或移动，不由 DM 连续代打。
- 观察队友如何根据亲历事件协助、拒绝或作出其他选择；[行动规则](<../docs/npc-autonomy.md>)由框架约束，具体模型表现不作通过承诺。
- 抵达晨光出口完成冒险，之后可回顾但不能继续改变已结束的游戏。NPC 亲密度、记忆、知情只属于当前存档，不写入全局角色库。

这是简化短篇，不是完整 D&D 5e：d20 + 固定修正，自然 1 失败、自然 20 成功，暴击双倍固定伤害。真实在线模型和 GUI 完整游玩仍需另行验收。

## 修改、打包与导入

[下载/导入示例 ZIP](<graystone.zip>) · [剧本配置](<graystone/adventure.yaml>) · [包清单](<graystone/manifest.yaml>)

在项目根目录执行：

```sh
npm run build:demo
```

构建脚本生成示例 ZIP 并通过正式解析器验证。ZIP 根级清单引用 adventure、角色 YAML/JSON 以及可选静态图片，不套外层目录。字段、5 MiB 压缩/20 MiB 展开/128 项等限额、禁止内容、版本幂等和快照规则集中见[剧本格式](<../docs/adventure-format.md>)。

内置初始化可通过受信任的 `store.importDirectory()` 读取示例目录，但不要向远端用户暴露此文件系统路径接口。锁、原子写盘、坏档处理与备份步骤见[开发与恢复](<../docs/development-and-recovery.md>)；不要删除存档或未知锁来跳过错误。
